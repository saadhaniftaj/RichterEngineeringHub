# Richter Engineering — Spare Parts Hub

Internal document extraction and search platform for Richter Engineering GmbH.  
Extracts structured parts data from PDF manuals using AWS Textract and makes it searchable via a modern web interface.

## Features

- 📄 Upload multi-page PDF parts manuals (up to 3,000 pages per document)
- ⚡ Async processing pipeline — no timeouts, no page limits  
- 🔍 Two-tier search: exact phrase match first, fuzzy closest-match fallback
- 📌 Click any result → PDF opens in new tab at the exact matched page
- 🗂️ Documents tab with live processing status (Processing → Indexed)
- 🗑️ Delete documents — removes from S3, DynamoDB, and search index
- 🇩🇪 Deployed in eu-central-1 (Frankfurt) — closest AWS region to Germany
- 🔒 All AWS calls signed with SigV4 — no credentials exposed to browser

## Architecture

```
Upload → S3 → Lambda A (textract-kickoff) → Textract async
                                              ↓
                                        SNS notification
                                              ↓
                                    Lambda B (completion-handler)
                                              ↓
                                    OpenSearch (spare_parts index)
                                    DynamoDB (status tracking)

Browser Search → Next.js /api/search → OpenSearch (signed)
Browser Click  → Next.js /api/download → S3 presigned URL + #page=N
```

## Tech Stack

| Layer | Service |
|---|---|
| Frontend | Next.js 14 (App Router) |
| Storage | Amazon S3 |
| OCR / Extraction | Amazon Textract (async) |
| Search | Amazon OpenSearch 2.11 (t3.small) |
| Status Tracking | Amazon DynamoDB (PAY_PER_REQUEST) |
| Event Bus | Amazon SNS |
| Compute | AWS Lambda (Python 3.11) |
| Auth | IAM SigV4 signed requests |

## Deploy to a New AWS Account

```bash
# 1. Configure AWS credentials
aws configure

# 2. Run the full deploy script (targets eu-central-1)
bash infra/deploy.sh

# 3. Start the frontend
cd frontend/spare-parts-hub
npm install
npm run dev
```

The script will:
- Create S3 bucket, SNS topic, DynamoDB table
- Create all IAM roles with least-privilege policies
- Create OpenSearch domain with n-gram index mapping
- Deploy both Lambda functions (with dependencies bundled)
- Wire S3 → Lambda A and SNS → Lambda B triggers
- Write `.env.local` for the frontend automatically

> ⚠️ OpenSearch domain creation takes ~15 minutes. The script waits automatically.

## Environment Variables

Set in `frontend/spare-parts-hub/.env.local` (auto-generated by deploy script):

```env
NEXT_PUBLIC_AWS_REGION=eu-central-1
AWS_REGION=eu-central-1
AWS_S3_BUCKET=spare-parts-docs-{ACCOUNT_ID}
OPENSEARCH_ENDPOINT={domain-endpoint}
OPENSEARCH_INDEX=spare_parts
DYNAMODB_TABLE=spare-parts-doc-status
```
